# 全部 CLI 参数（按 `--help` 实测整理，默认值以代码为准）

> 入口列：**①** 一键 `satellite_imagery_cn.py`、**②** `download_imagery.py`（bbox 模式）、**③** `make_map.py`（专题图）。

### 范围与坐标系

| 参数 | 默认 | 入口 | 说明 |
|---|---|---|---|
| `--zoom` | `17` | ①② | 0–19。区县 z17≈5.5k 瓦片；z18≈2.2 万（默认可跑）；z19 超瓦片上限需 `--force` |
| `--output` | `<名>_satellite_z<zoom>.tif` | ①②③ | 输出路径（③ 默认 `<输入>_map.png`） |
| `--parent` | — | ① | 同名消歧（`朝阳区 --parent 长春市`） |
| `--epsg` | `3857` | ①② | `4326` 重投影到 WGS84，便于与 cn-dem 的 DEM 叠加 |
| `--pad` | `0.10` | ① | 下载范围相对行政区包围盒外扩比例，给研究区留白（v1.5.2） |
| `--max-tiles` | `60000` | ①② | 瓦片数安全上限 |
| `--force` | off | ①② | 越过瓦片上限（谨慎，可能生成 GB 级文件） |
| `--refresh` | off | ① | 重建区划索引 |

### 影像质量

| 参数 | 默认 | 入口 | 说明 |
|---|---|---|---|
| `--source` | `esri` | ①② | 可选值取自 `download_imagery.SOURCES` 注册表（v1.7.8 起两个入口同源，新增影像源只需改 `SOURCES`）：`esri`（Esri World Imagery，国内直连）/ `google`（需代理） |
| `--balance-mode` | `none` | ①② | `none` 保留原片色彩；`offset` 仅中位数亮度偏移；`percentile` 5/95% 线性拉伸（可能放大色差，谨慎） |
| `--no-balance` | off | ①② | 等价 `--balance-mode none` |
| `--feather` | ① `24` / ② `0` | ①② | 瓦片边界交叉淡化像素宽，建议 16~32，0=关闭 |
| `--fill-holes` | **默认开** | ② | 失败瓦片用全局均值填充，避免黑块 |
| `--no-fill-holes` | off | ①② | 失败瓦片留黑，便于人工标记缺失区 |
| `--fill-blanks` | off | ①② | 纯色/空瓦片（无数据区）也填充；默认保留原色并把计数写入 `blank_tiles` |

### 下载性能与交互

| 参数 | 默认 | 入口 | 说明 |
|---|---|---|---|
| `--max-workers` | `12` | ①② | 并发下载线程数（下载是瓶颈，适度提高可加速） |
| `--timeout` | `15` | ①② | 单瓦片下载超时秒，失败快速跳过 |
| `--retries` | `2` | ①② | 单瓦片重试次数 |
| `--mem-budget-mb` | `2048` | ①② | 解码瓦片数组的内存预算；超出自动转流式（峰值内存与面积解耦） |
| `--progress-sec` | `2.0` | ①② | 下载进度按时间刷新间隔（秒） |
| `--no-cache` / `--clean-cache` | off | ①② | 跳过 / 清空瓦片缓存（默认 `scripts/_tiles/`） |
| `--dry-run` | off | ①② | 只预检瓦片数 / 块尺寸 / 像元体量 / 是否超限，不下载不出图 |
| `--version` | off | ①②③ | 打印版本（排在必填参数校验之前） |

### 专题图

| 参数 | 默认 | 入口 | 说明 |
|---|---|---|---|
| `--map` | off | ① | 下载后直接出专题图；给 `--title` 也等价触发 |
| `--title` / `--subtitle` | 元数据 `region_name` / 无 | ①③ | 副标题默认不生成（v1.5.3 起），需要时显式传 |
| `--map-output` | `<tif>_map.png` | ① | 专题图输出路径 |
| `--map-dpi`（③ 为 `--dpi`） | `make_map.DEFAULT_MAP_DPI` = `200` | ①③ | 输出分辨率；打印/投稿用 300。① 不传则回落到 `make_map` 的默认值（v1.7.8 起单一来源） |
| `--max-side` | `make_map.DEFAULT_MAX_SIDE` = `3500` | ①③ | 渲染最长边像素上限（同上，v1.7.8 起单一来源） |
| `--supersample` | `2.0` | ①③ | 源读取超采样倍数；`1.0` 最快（见「性能」权衡表）。v1.7.8 起降采样读改用 `average` 核，同倍数下更快且无混叠 |
| `--pdf` | off | ①③ | **额外**输出同名 PDF（PNG 主图恒生成） |
| `--boundary` | 本区县缓存边界 | ①③ | 研究区边界 GeoJSON 路径 / JSON 串 |
| `--no-boundary` | off | ① | 不叠加区界红线 |
| `--boundary-color` / `--boundary-lw` | `#d81e06` / `1.6` | ①③ | 边界线颜色 / 线宽 |
| `--legend-pos` | `se` | ①③ | 图例位置：`se`=**固定右下角**（v1.7.4 默认）；`auto`=按区界压力自动避让（v1.7.3）；也可强制 `sw/ne/nw/e/w/s/n` |
| `--panel-alpha` | `1.0` | ①③ | 比例尺/图例白色衬底面板不透明度（v1.7.4）：`1.0`=全不透明（区界线 100% 不干扰）、`0.9`=底图微透、`0`=不要面板 |
| `--no-graticule` / `--no-scale-bar` / `--no-north-arrow` / `--no-legend` | off | ①③ | 分别关闭经纬网 / 比例尺 / 指北针 / 图例 |

> **下载调优（v1.2 起）**：请求走 `requests` 连接池复用；单瓦片超时 15 s、重试 2 次，
> **失败快速跳过**而非长时间阻塞或崩溃；坏缓存自动检测并重下。
